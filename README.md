# Portfolio

A responsive personal portfolio website built with **HTML5, CSS3 and JavaScript**, featuring smooth animations, scroll-reveal effects, a project showcase and a skills section.

🔗 **Live Demo:** https://kirthana739.github.io/Portfolio/

---

## ✨ Features

- 📱 **Fully responsive** – works on mobile, tablet and desktop
- 🎞️ **Smooth animations** and transitions
- 👀 **Scroll-reveal effects** that animate sections as you scroll
- 🗂️ **Project showcase** highlighting my work
- 🛠️ **Skills section** with the technologies I use
- ⚡ Lightweight – a single-page site with no frameworks or build step

## 🚀 Getting Started

### Run locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/kirthana739/Portfolio.git
   ```
2. **Open the project folder**
   ```bash
   cd Portfolio
   ```
3. **Open `index.html`** in your browser (or use the *Live Server* extension in VS Code).

No installation or build tools required.

### Deploy on GitHub Pages

1. Go to **Settings → Pages** in your repository.
2. Under **Source**, select the `main` branch and the `/ (root)` folder.
3. Save – your site will be live at `https://<your-username>.github.io/Portfolio/`.

---

## 🎨 Customization

Open `index.html` and update:

- **Name, tagline and about text** in the hero/about section
- **Projects** – replace titles, descriptions and links in the project cards
- **Skills** – add or remove technologies
- **Contact links** – GitHub, LinkedIn, email
- **Colors and fonts** – edit the CSS variables/styles at the top of the file
