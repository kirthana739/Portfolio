# Portfolio

A responsive personal portfolio for **Kirthana Ganesh Kunder**, a third-year BCA student building data analytics platforms and full-stack web apps. It is a single-page site built with **HTML5, CSS3 and vanilla JavaScript**, with no frameworks and no build step.

🔗 **Live site:** [https://kirthana739.github.io/Portfolio/](https://kirthana739.github.io/Portfolio/)

---

## ✨ Features

- 📱 **Fully responsive**: works on phones, tablets and desktops
- 🎞️ **Hero animations**: the name rises out of a mask, the photo wipes in, and on desktop the photo tilts with the mouse
- 🌿 **Green and sand theme**: forest green, emerald, mint and warm cream with gold accents
- 📊 **Animated numbers band**: counters for project results (9,000+ orders analysed, 92/100 data quality score and more) that count up on scroll
- 🧰 **Scrolling tech strip**: the tools I use, paused on hover
- 🌫️ **Blur-and-settle scroll reveals** and a gold scroll-progress bar
- 🗂️ **Project showcase** with GitHub links for every project
- 🧭 **Active navigation highlight** as you scroll
- ♿ **Accessible**: keyboard focus styles, alt text, and animations switch off for visitors who prefer reduced motion
- ⚡ **Lightweight**: one `index.html` file with the photo embedded

## 🛠️ Getting Started

### Run locally

1. **Clone the repository**

   ```
   git clone https://github.com/kirthana739/Portfolio.git
   ```

2. **Open the folder**

   ```
   cd Portfolio
   ```

3. **Open `index.html`** in your browser (or use the *Live Server* extension in VS Code).

No installation or build tools needed. An internet connection is only used to load the Google Fonts.

### Deploy on GitHub Pages

1. Go to **Settings → Pages** in your repository.
2. Under **Source**, choose the `main` branch and the `/ (root)` folder.
3. Save. The site goes live at `https://<your-username>.github.io/Portfolio/`.

## 🎨 Customization

Open `index.html` and update:

- **Colours:** the CSS variables at the top of the `<style>` block (`--cream`, `--ink`, `--gold`, `--gold-light`, `--paper`, `--watch`)
- **Text and stats:** the hero, About section and numbers band
- **Projects:** the cards inside the `#projects` section
- **Skills, experience and certifications:** the matching sections
- **Photo:** replace the `src` of the image inside `.photo-wrap` with your own base64 image or a file path
